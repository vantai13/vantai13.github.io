01 / Network Digital Twins

A digital twin for intelligent network management

Connecting an SDN testbed to a living network model, with bidirectional synchronization, what-if analysis, and a closed control loop.

The problem

Network telemetry is useful only when it can support a timely and appropriate operational decision. A monitoring dashboard alone does not close the gap between observing the network and acting on it.

Why this matters to me

I wanted to build a network digital twin whose state could be inspected, whose assumptions could be tested, and whose commands could be traced back to observed changes in a testbed.

My role

Project Lead for a UIT-supported undergraduate research project, advised by Dr. Huynh Van Dang. My work covered the SDN testbed, synchronization layer, anomaly detector, and closed-loop controller.

Technical approach

  1. Built a Mininet / Ryu SDN testbed and represented hosts and links as Eclipse Ditto Things.
  2. Implemented upward telemetry synchronization and a downward command path, verifying control actions through the returning network state.
  3. Added a detector trained on normal traffic, a bounded what-if model, and a controller that rate-limits a host identified as causing congestion.
  4. Preserved raw observations, model versions, evaluation criteria, and scripts for offline reproduction. The system also includes an AWS automation integration.

Limitations & open questions

  • Experiments use a small, single-machine testbed. They do not establish performance on a production network.
  • The detector caught 4/4 flood and bottleneck-shift incidents, but bandwidth-reduction detection was 0.40 against a target of 0.875. Maximum detection delay was about 20 s against a 3 s target.
  • Zero false-alarm events were observed over approximately two normal-traffic hours; this does not imply a zero false-alarm rate. The stored one-sided 95% upper bound is about 1.50 events/hour.
  • The controller throughput result has a possible ceiling effect noted in the stored analysis. The what-if model has an explicit operating region.
